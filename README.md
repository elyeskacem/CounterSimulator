# MotoDash

A motorcycle dashboard: GPS speed, odometer, trip meter, fuel reminder (every 220 km → pay 20 DT) and oil-change (vidange) reminder every 1000 km.

| Folder | What it is |
|---|---|
| [`web/`](web/) | The web app (PWA). Live at https://elyeskacem.github.io/CounterSimulator/ |
| [`ios/`](ios/) | The native iPhone app (Swift/SwiftUI): works in the background, shows the ride in the Dynamic Island |

See each folder's README for how to run it.
